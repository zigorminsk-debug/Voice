# Схема связей ЦОД

Нативное Windows-приложение на Go для быстрого создания интерактивной схемы серверов и связей между ними.

## Возможности

- палитра готовых объектов: **Обмен данными**, **1С сервер**, **SQL Server**, **Файловый сервер**, **Почтовый сервер**, **Терминальный сервер**;
- добавление и перетаскивание серверов мышью;
- создание связей между любыми двумя объектами;
- редактирование названия, IP/имени хоста и многострочного описания;
- удаление объекта вместе с его связями;
- сохранение и открытие схем в читаемом формате JSON;
- стартовый пример схемы, который можно сразу переделать под свой ЦОД;
- полностью нативный интерфейс Win32, без браузера и внешних библиотек.

## Как пользоваться

1. Нажмите инструмент слева — объект появится на поле.
2. Перетащите блок мышью в нужное место.
3. Выберите блок и заполните свойства справа, затем нажмите **Применить изменения**.
4. Нажмите **Создать связь**, затем по очереди выберите два блока.
5. Сохраните результат кнопкой **Сохранить как…**.

## Сборка в Windows

Требуется Go 1.23 или новее.

```powershell
./build.ps1
```

Или вручную:

```powershell
go test ./...
go build -trimpath -ldflags="-s -w -H windowsgui" -o "ЦОД.exe" .
```

Полученный `ЦОД.exe` не требует установки. Файлы схем (`.json`) можно передавать и редактировать вручную. Поле `label` у связи задаёт подпись линии.

## Сборка через GitHub Actions

Workflow **ЦОД** автоматически запускается при обновлении рабочей ветки. Готовый Windows-файл публикуется на странице запуска Actions как артефакт **ЦОД** со сроком хранения 30 дней.

## Формат проекта

Вся модель вынесена в `diagram.go` и покрыта тестами. Windows GUI находится в `main_windows.go`; проект использует только стандартную библиотеку Go.
