# Voice Commander для Android

Android-приложение на Kotlin: слушает кодовое слово и распознаёт голосовые команды:

- **«ответить» / «прими звонок»** — ответить на входящий звонок;
- **«отклонить» / «сбрось звонок»** — отклонить звонок;
- **«фонарик включи» / «фонарик выключи»** — управлять вспышкой.

Можно произнести команду сразу после кодового слова: **«телефон, фонарик включи»**. Кодовое слово по умолчанию — «телефон», его можно изменить в приложении.

## Запуск и локальная сборка

Откройте корень репозитория в Android Studio (JDK 17, Android SDK 35) или выполните:

```bash
./gradlew assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Для работы звонков назначьте приложение телефоном по умолчанию в системном диалоге. При первом запуске разрешите доступ к микрофону; для фонарика нужно разрешение камеры. Android 12+ может запросить разрешение для подключённых Bluetooth-устройств, Android 13+ — для уведомлений.

## Автосборка и публикация релизов

GitHub Actions (`.github/workflows/android.yml`) запускает lint, unit-тесты и debug-сборку при push в ветку, pull request в `main` и вручную. Debug APK доступен как Actions artifact.

Для подписанного релиза создайте и отправьте в GitHub тег формата `vMAJOR.MINOR.PATCH`, например:

```bash
git tag v1.0.1
git push origin v1.0.1
```

Action соберёт `app-release.apk`, проверит его подпись и создаст GitHub Release с APK и `update.json`. `versionName` берётся из тега; `versionCode` монотонно увеличивается по номеру запуска GitHub Actions.

### Секреты для постоянного ключа

Перед первым релизом добавьте в **Settings → Secrets and variables → Actions** следующие repository secrets:

| Secret | Значение |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | Keystore с постоянным release-ключом, закодированный в Base64 в одну строку |
| `ANDROID_KEYSTORE_PASSWORD` | Пароль keystore |
| `ANDROID_KEY_ALIAS` | Alias ключа подписи |
| `ANDROID_KEY_PASSWORD` | Пароль ключа |

Для Linux Base64-значение можно получить командой `base64 -w0 путь/к/release-key.jks`; на macOS — `base64 -i путь/к/release-key.jks | tr -d '\\n'`. Добавляйте секреты напрямую в настройки GitHub — не помещайте keystore, пароли или приватный ключ в Git и не отправляйте их сообщением. Храните отдельную резервную копию keystore: без этого же ключа Android не примет обновление поверх уже установленной версии.

В найденном архиве был только стандартный Android **debug keystore**. Он не используется для релизов и не является постоянным release-ключом. APK, ранее собранный с debug-ключом, нельзя обновить поверх сборкой с другим ключом: перед переходом на первый release APK его потребуется удалить и установить релиз заново (данные приложения при удалении могут потеряться).

## Обновления в приложении

При открытии приложения оно проверяет публичный GitHub Release. Если появилась новая версия, приложение предлагает скачать APK; после загрузки Android показывает системное подтверждение установки. Для установки из GitHub может понадобиться разрешить этому приложению **установку неизвестных приложений** в настройках Android.

Android не разрешает обычному приложению устанавливать обновления полностью бесшумно. Проверка выполняется при открытии приложения; если оно закрыто, сообщение об обновлении будет показано при следующем запуске. Для публикации через Google Play следует использовать механизм обновлений Play Store вместо sideload-установщика.

## Ограничения Android

- Стороннее приложение не может использовать системный always-on hotword. Для прослушивания нужен запущенный foreground service с постоянным уведомлением; некоторые производители ограничивают его работу в фоне.
- Приложение сначала пробует системный офлайн-распознаватель, если он доступен. Иначе речь может обрабатываться установленным сервисом распознавания и требовать интернет.
- Bluetooth-маршрут зависит от версии Android, гарнитуры и производителя телефона.
- Ответ и отклонение обычных сотовых звонков доступны после назначения приложения телефоном по умолчанию. Экстренные вызовы остаются под контролем системы.
- Минимальная версия — Android 8.0 (API 26). В репозитории хранятся исходники; APK и keystore не коммитятся.
