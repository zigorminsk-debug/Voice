# DocDiff — сравнение таблиц Excel и документов Word

Настольное приложение для Windows с HTML-интерфейсом: сравнивает две версии
таблиц **Excel** (`.xlsx` / `.xlsm`) и документов **Word** (`.docx`), находит
изменённые строки и абзацы и **отмечает их комментариями** прямо в копии нового
файла.

Всё выполняется локально: файлы не загружаются в интернет.

---

## Возможности

| | Excel (.xlsx, .xlsm) | Word (.docx) |
|---|---|---|
| Сравнение | построчно, с учётом вставок/удалений строк (LCS) | по абзацам и таблицам (LCS) |
| Детализация | до ячейки: «B: 100 → 150» | до слова: удалено/добавлено подсвечено |
| Комментарии | на каждой изменённой ячейке и добавленной строке | на каждом изменённом/добавленном/удалённом блоке |
| Подсветка | жёлтая — изменено, зелёная — добавлено | жёлтая — изменено, зелёная — добавлено, красная — удалено |
| Формулы | изменение формулы помечается даже при равном результате | — |
| Удалённые данные | лист «Отчёт о сравнении» | вставка пометки «[Удалено] …» с зачёркиванием |
| Отчёт | отдельный лист в книге | комментарии в тексте |
| HTML-отчёт | да (печать в PDF через браузер) | да |

* Изменённые строки таблиц Excel получают **комментарии вида**:
  `Изменено в строке 5: B: «100» → «150»; D: «Омск» → «Томск»`.
* Добавленные строки подсвечены зелёным с комментарием
  `Строка 7 добавлена (отсутствует в оригинале): …`.
* Удалённые строки попадают в лист **«Отчёт о сравнении»** со всеми
  изменениями (тип, лист, номера строк, детали).
* **Формулы сравниваются всегда**: если формула изменилась, а результат
  совпадает, ячейка всё равно помечается комментарием
  `B: формула «=2+2» → «=1+3» (значение «4» не изменилось)`.
* Доступно сравнение **по ключевому столбцу** (например, по артикулу):
  строки сопоставляются по значению ключа, а не по порядку — перестановки
  не считаются изменениями.

## Быстрый старт (Windows)

1. Установите [Go 1.20+](https://go.dev/dl/) (если ещё не установлен).
2. Соберите приложение:

   ```bat
   build.bat
   ```

3. Запустите:

   ```bat
   dist\docdiff.exe
   ```

4. В браузере откроется интерфейс: перетащите два файла (оригинал и новую
   версию), нажмите **«Сравнить файлы»** и скачайте готовый файл с
   комментариями.

### Режим командной строки

Флаги указываются **до** имён файлов:

```bat
dist\docdiff.exe old.xlsx new.xlsx
dist\docdiff.exe old.docx new.docx -o report.docx
dist\docdiff.exe -key A -report report.html old.xlsx new.xlsx
```

* `-key A` — сравнивать строки по ключевому столбцу A (артикул, код и т.п.)
* `-report report.html` — дополнительно сохранить HTML-отчёт
* `-o имя.xlsx` — задать имя файла с комментариями

Результат — файл `new_с_комментариями.xlsx` (или `.docx`) и сводка в консоли.

## Сборка

```bat
:: Windows
build.bat                     → dist\docdiff.exe
```

```sh
# Linux / macOS
./build.sh                    # под текущую ОС
./build.sh windows            # кросс-сборка docdiff.exe
```

Ручная сборка:

```sh
go build -o dist/docdiff ./cmd/docdiff
```

Внешних зависимостей нет — используется только стандартная библиотека Go,
поэтому `go build` работает без доступа к сети.

## Веб-интерфейс

При запуске поднимается локальный веб-сервер (по умолчанию
`http://127.0.0.1:8765`) и открывается браузер.

```
docdiff -addr 127.0.0.1:9000   # другой порт
docdiff -open=false            # не открывать браузер
```

* Два поля перетаскивания (оригинал / новая версия), формат определяется
  автоматически.
* Для таблиц Excel — выбор режима: **по порядку строк** или **по ключевому
  столбцу** (буква столбца с артикулом/кодом).
* Сводка: сколько строк/абзацев изменено, добавлено, удалено.
* Фильтры «Все / Изменено / Добавлено / Удалено».
* По строкам Excel — ячеечный диф с формулами и контекстом строки
  (ключевые значения); по абзацам Word — диф на уровне слов.
* **«Файл с комментариями»** — готовая копия нового файла.
* **«HTML-отчёт»** — самодостаточный отчёт в новой вкладке; печатается
  в PDF через Ctrl+P (стили печати уже включены).

## Как это работает

* **Excel**: книга разбирается как OOXML (zip + XML): общие строки, стили с
  форматами дат, формулы (по сохранённому значению). Строки выравниваются
  алгоритмом LCS, соседние «удалена + добавлена» считаются изменённой строкой.
  В копию нового файла добавляются: комментарии Excel (`xl/comments*.xml` +
  VML-фигуры), заливка изменённых ячеек (через производные стили) и лист
  «Отчёт о сравнении».
* **Word**: документ разбирается на абзацы и таблицы; сравнение — LCS по
  блокам, для изменённых абзацев — диф на уровне слов. В копию нового файла
  добавляются настоящие комментарии Word (`word/comments.xml` с
  `commentRangeStart/End`), подсветка изменённых фрагментов и пометки
  «[Удалено] …» для удалённых абзацев.

## Структура проекта

```
cmd/docdiff/          точка входа: сервер, CLI, открытие браузера
internal/app/         HTTP API и статический HTML-интерфейс (web/)
internal/diff/        модели результатов и алгоритмы сравнения (LCS)
internal/ooxml/       контейнер OOXML (zip+XML) и мини-сканер тегов
internal/report/      самодостаточный HTML-отчёт (печать в PDF)
internal/xlsx/        чтение и аннотирование книг Excel
internal/docx/        чтение и аннотирование документов Word
build.bat             сборка Windows
build.sh              сборка Linux/macOS (+ кросс-сборка Windows)
```

## Тесты

```sh
go test ./...
```

Тесты формируют файлы Excel/Word «с нуля», прогоняют сравнение и проверяют,
что аннотированные файлы содержат комментарии, подсветку и лист-отчёт.

## Ограничения

* Форматы старого поколения `.doc` / `.xls` не поддерживаются — сохраните
  файлы как `.docx` / `.xlsx`.
* Если в исходном листе уже есть комментарии или рисунки к комментариям,
  новые комментарии для этого листа добавляются только в отчёт (заливка и
  лист-отчёт работают).
* Сравнение идёт по видимым значениям ячеек и по формулам; оформление
  шрифтов и объединения ячеек в сравнении не участвуют.
* В режиме ключевого столбца строки с одинаковым ключом сопоставляются
  в порядке появления.
